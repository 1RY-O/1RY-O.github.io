Projects

Lumis — AI-Powered Journaling & Reflection Platform

React · Vite · Firebase · Firestore · Node.js · Express · Google Cloud Run · Gemini API · 2025–2026

  • Open-source full-stack AI journaling prototype for structured reflection and idea exploration.
  • Integrates the Gemini API to transform unstructured entries into validated, structured reflections using JSON-based outputs.
  • Authenticated user flows with Firebase Authentication and per-user Firestore data isolation.
  • Backend architecture on Node.js/Express and Google Cloud Run with server-side API credential management via Cloud Secret Manager.
  • Built with an AI-assisted dev workflow (Cursor, Manus 1.6 Lite) integrated with GitHub for rapid iteration.
  • Designed as a reference for teaching peers how real-world AI API integration works.
