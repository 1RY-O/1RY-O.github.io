Lumis

An AI-powered journaling and reflection platform. Raw entries in, structured insight out — quietly, privately, without the noise.

01 — Problem
Journals accumulate; insight doesn't. Speaking to a page is easy — reading your own story back clearly is not.
02 — Idea
An AI layer that reads between the lines of raw entries and surfaces quiet, human-scale reflections.
03 — System
Journal client · server-side retrieval · grounded summarization — built around the user's own text.
04 — Prototype
A working prototype, currently being refined and tested — not a production service.

React / Vite / Firebase / Firestore / Node.js / Express / Cloud Run / Gemini API
